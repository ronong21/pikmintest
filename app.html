찾을 버섯

찾기 설정
인원 제한 (이 인원 이하만 알림) 한 바퀴에 볼 칸 수 (넓을수록 오래) 자동으로 멈추기 (배터리 아끼기) 넓게 보기 (광역 지도 최대 줌아웃 → 한 화면에 2~3배 넓게) 본 곳 기억 (중지했다 같은 자리에서 다시 시작하면, 이 시간 안에 본 곳은 건너뜀) 후보 검수 (거대 버섯 찾을 때 조건 밖 후보도 사진+좌표 30장, 알림 없음) 발열 줄이기 (백그라운드 화질. 낮추면 덜 뜨겁지만 인원 숫자를 잘못 읽을 수 있음) 버섯 누르는 시간 (블룸은 짧게 눌렀다 떼야 이름표가 떠요)

버섯 후보 = 찾는 버섯을 발견해 인원까지 확인한 수(인원 초과·이름표 놓침 포함), 알림 보냄 = 조건에 맞아 좌표까지 얻은 수.
찾으면 폰 알림 + 아래 [찾은 내역]에 쌓여요. 이 화면을 닫아도 계속 찾아요.

      • 찾는 순서: 내 위치에서 가까운 곳부터 점점 바깥으로 넓혀 가요. 처음 나가는 방향은 매번 랜덤이에요. 한 번 본 곳은 다시 안 봐요.
        • 
      
      • 중지했다 다시 시작하면: 같은 자리(약 100m 안)면 최근 2시간 안에 본 곳은 건너뛰고 이어서 바깥쪽을 봐요. 2시간이 지난 곳은 버섯이 새로 생겼을 수 있어 다시 봐요. (시간은 찾기 설정의 '본 곳 기억')
        • 
      
      • 위치를 옮기면(블룸 GPS 등): 새 자리에서 처음부터 봐요.
        • 
      
      • 같은 곳을 처음부터 다시 보고 싶으면: [리셋], 또는 찾기 설정의 '본 곳 기억'을 '기억 안 함'으로.
        • 
      
      • 이미 알린 버섯도 다시 알리게 하려면: [찾은 내역]의 [전체 지우기]. (24시간 안에 알린 버섯은 다시 안 알려요)
        • 
      
      • [임시 파일 정리] = 사진만 지워 용량 정리. 찾기는 계속되고, 찾은 내역·검수 기록은 그대로예요. (사진은 원래 정해진 장수만 쌓여서 자주 안 눌러도 돼요)
        • 
      
      • [리셋] = 완전히 처음 상태로. 찾기를 멈추고 찾은 내역·사진·검수 기록·본 곳 기억을 전부 지워요. 다시 [찾기 시작]하면 처음부터 돌아요.
