# 버섯 탐지기 (피크민 블룸) — 인수인계 문서

> 현재 버전 **v45 (2026-11-02)** · 원본 폴더 `D:\BX디자인\2026\기타\바이브코딩\pikmin` · 폰 배포 gist `ronong21/30919049d2c3c99b192e806267b0a481`

피크민 블룸 **광역 지도**를 자동으로 드래그하며 원하는 버섯(예: 거대·중형 화려한 버섯)을 찾는다.
그중 **인원 4명 이하**(배지 없음 포함)인 것만 골라 **이름표 → 여기로 이동 → 지도 앱 열기**로 **좌표**를 얻고, 폰 알림과 찾은 내역에 남긴다.
게임 서버나 메모리는 건드리지 않고 **화면 인식 + 화면 터치**만 쓴다.

## 2. 폰에서 쓰는 법 (사용자)

- **홈 화면 [버섯찾기]** 위젯 하나로 쓴다.
  - 앱이 꺼져 있을 때 누르면: 최신 버전 받기 → Shizuku 확인 → 앱 화면(`http://127.0.0.1:8765`)이 브라우저로 열린다.
  - 앱이 이미 켜져 있을 때 누르면: 업데이트나 재시작 없이 화면만 다시 연다.
- **앱 화면**
  - 버섯 카드를 고르고, 백그라운드 켬/끔을 정한 뒤 **[찾기 시작] / [중지]**를 누른다.
  - 화면에 보이는 것:
    - 진행 숫자: 확인한 칸, 버섯 후보, 이름표 놓침, 알림 보냄
    - 알기 쉬운 진행 기록
    - 지금 블룸 화면
    - 찾은 내역: [복사] [공유] [지도]
    - 확인용 사진
    - 새 버섯 등록
  - **찾기 설정**:
    - 인원 제한
    - 한 바퀴 칸 수
    - 자동으로 멈추기
    - 넓게 보기(줌아웃)
    - 발열 줄이기(화질)
    - 누르는 시간
- **업데이트**: 앱이 30분마다 확인한다. 화면 위에 **[지금 업데이트]**가 뜨면 누른다. 설치한 뒤 다시 켜지고, 찾던 것은 이어서 찾는다. 제목 옆에 버전이 표시된다(`v45 · 날짜`).
- **리셋**: 앱 맨 아래 **[리셋]**은 찾기를 멈추고, 찾은 내역·확인용 사진·검수 기록·진행 기록을 모두 지운다. 다시 시작하면 처음 자리부터 돈다.
- **거대 후보 검수**: 거대 버섯을 찾을 때 조건(인원)에 안 맞는 후보도 사진과 좌표를 최대 30장까지 남긴다. 알림을 보내지 않고 카운트에도 넣지 않는다. 설정의 '후보 검수'로 끌 수 있다. 저장 위치는 `~/scout/audit/`이다.
- **임시 파일 정리**: 앱이 켜질 때마다 쓰다 만 사진 같은 찌꺼기를 자동으로 지운다. [임시 파일 정리] 버튼은 확인용 사진·기록 사진을 지우고, 찾은 내역·검수 기록은 그대로 둔다. 쌓이는 파일은 원래 개수가 정해져 있다(확인용 사진 4장 덮어쓰기, 기록·검수 각 최대 30장).
- **GPS 주말 모드**(스위치): [찾기 시작] 때 현지 시각이 주말인 도시로 폰 위치를 옮긴다(셸 모의 위치 `cmd location providers set-test-provider-location`, gps·network·fused). 주말인 지역 중 사람 많은 순위(`GPS_SPOTS`의 숫자)가 가장 높은 지역 → 그 지역의 붐비는 곳·적당히 붐비는 곳 중 랜덤. 앱 서버가 30초마다 위치를 다시 넣는다. [원래 위치로]·[모두 끄기]로 원래 위치. 주말인 곳이 없으면(한국 화~목) 안 옮긴다. 블룸이 모의 위치를 알아채는지는 폰에서 미확인.
- **블룸 소리 끄기**: `appops set com.nianticlabs.pikmin PLAY_AUDIO ignore`. 다른 앱 소리는 그대로다.
- **끄기**: 앱의 **[모두 끄기]**를 누르면 블룸·탐지기·Termux가 꺼진다. **Shizuku는 켜 둔다.**
- **재부팅한 뒤에만** 와이파이에 연결하고 Shizuku 앱에서 [시작]을 누른다. 무선 디버깅은 와이파이가 있어야 켜진다. 켠 뒤에는 데이터만 써도 된다.
- **주의**
  - 백그라운드로 찾는 동안 블룸 앱을 직접 열지 않는다. 화면을 서로 차지하려고 엉킨다.
  - Termux를 Exit로 닫지 않는다. 앱이 꺼진다.
- **새 버섯 등록 (매달 이벤트)**
  1. 블룸 광역 지도에서 그 버섯을 눌러 **검은 이름표가 보이게** 한 다음, 크기별(거대·중형·소형)로 스크린샷을 한 장씩 찍는다.
  2. 앱의 [새 버섯 등록]에 이름(예: `반짝이는 버섯`)을 적고 사진을 고른 뒤 **[자동 등록]**을 누른다.
  3. 이름표가 화면 끝에 잘린 사진이면, 앱이 띄운 사진에서 그 버섯을 **한 번 톡** 누르면 된다.
  4. 등록한 버섯은 `~/scout/my_targets/`에 저장되고, 업데이트해도 지워지지 않는다.

## 3. 처음 설치 (새 폰)

1. **Termux**와 **Termux:Widget**은 GitHub 릴리스에서 받는다. Play 스토어 버전과 섞으면 안 된다. **Shizuku**는 Play 스토어에서 받는다.
2. Termux에서 아래를 실행한다.
   ```
   pkg install python android-tools termux-api python-numpy opencv-python dbus
   termux-setup-storage
   ```
3. Shizuku를 무선 디버깅으로 시작한다.
   1. Shizuku 앱에서 '터미널 앱에서 사용'을 눌러 rish를 `Download/shizuku`로 내보낸다.
   2. rish를 `~/bin/rish`로 복사하고, 파일 안의 `PKG`를 `com.termux`로 바꾼다.
4. 설치(이후 업데이트도 같은 줄)를 한다.
   ```
   curl -sL "https://gist.githubusercontent.com/ronong21/30919049d2c3c99b192e806267b0a481/raw/scout_setup.sh?$(date +%s)" | bash
   ```
   설치할 때 Termux에 '다른 앱 위에 표시' 권한과 절전 예외도 같이 켠다.
5. 홈 화면에 Termux:Widget을 추가하고 **버섯찾기**를 고른다. 처음 실행하면 알림이 오는지 확인하는 질문이 한 번 나온다.
6. (권장) 설정 → 애플리케이션 → Termux와 Shizuku → 배터리 → **제한 없음**

## 6. 알아낸 것 / 함정 (다음 사람이 꼭 알아야 할 것)

**Shizuku·도우미**
- **Shizuku rish**
  - 출력이 가끔 비어서 온다. 그래서 중요한 확인은 여러 번 한다(블룸이 꺼졌는지는 3번, Shizuku 연결은 2번 연속 실패해야 '꺼짐').
  - 바이너리 출력은 깨지므로 화면 캡처는 파일로 받는다.
  - 부를 때마다 JVM이 새로 뜨기 때문에 자주 부르면 발열이 생긴다.
  - `timeout` 안에서 부를 때는 `--foreground`와 `</dev/null`을 꼭 붙인다.
  - Termux는 셸이 만든 사진 외 파일(예: id 파일)을 못 읽는다. 그래서 도우미의 출력은 `/data/local/tmp/*.log`에 쓰고 rish로 `cat`해서 읽는다.
  - 오래 도는 도우미는 `setsid nohup ... &`로 rish와 떼어 놓는다.
- **이 폰(삼성)은 app_process에서 `ActivityThread.getSystemContext()`를 부르면 SIGKILL(137)로 죽는다.**
  - 그래서 가상 화면은 `IDisplayManager.createVirtualDisplay`를 직접 부르고, 핀치는 `InputManager(Global).injectInputEvent`로 넣는다.
  - 화면 위 오버레이(떠 있는 중지 버튼)는 같은 이유로 쓸 수 없다. 그래서 중지는 앱 화면 버튼으로만 한다.

**블룸 조작**
- **블룸 터치**: 지도 위 버섯은 '짧게 눌렀다 떼야' 이름표가 뜬다. 그래서 `input swipe x y x y 100`처럼 제자리에서 누른다. `input tap`은 안 먹혔다.
- **드래그 뒤 지도가 미끄러지는 중에 누르면 '멈춤'으로만 먹힌다.** 그래서 `settle()`로 화면이 멈출 때까지 기다리고 버섯을 다시 찾은 뒤 누른다.
- **누르는 자리 4번 시도**: 몸통(갓보다 조금 아래) → 갓 → 밑동 → 2초 뒤 몸통(motionevent) 순서다. 갓 맨 위는 인원 배지·진행 표시와 겹쳐 터치를 가로챌 수 있어서 몸통부터 누른다. 실패하면 `scout_nolabel.jpg`(누르기 전·1·2·3번 뒤 4칸)와 진행 기록의 '진단: 누른 뒤 화면 변화 [...]'를 남긴다. 숫자가 0에 가까우면 터치가 안 들어간 것이다. 이어서 지도 전환 버튼으로 블룸이 터치를 받는지도 확인한다.
- **이름표 인식**: 누르기 전 화면에 없던 검은 덩어리가 누른 뒤 새로 생기면 이름표로 본다. 크기·위치는 따지지 않아서 3줄 이름표나 화면 끝에 잘린 이름표도 잡는다.
- **좌표**: `dumpsys activity activities`의 `query=위도,경도`에서 읽는다. 지도 앱을 열기 **전에** 있던 주소는 빼야 옛 주소를 잘못 읽지 않는다.
- **광역 지도 진입**: 안내 팝업 OK → 나침반 → 아래 두 아이콘 중 오른쪽 순서로 누른다(`ui/ok`, `ui/compass`, `ui/toggle_normal|wide`).
- **줌아웃**: 해도 버섯 아이콘 크기는 그대로이고 보이는 지역만 2~3배 넓어진다. 그래서 찾기를 시작할 때 한 번 최대로 줌아웃하고, 광역 지도에 다시 들어가야 할 때도 줌아웃한다.
- **탐색 순서와 본 곳 기억**
  - 내 위치(블룸 지도 가운데)에서 가까운 칸부터 바깥쪽으로 넓혀 가고, 처음 나가는 방향은 매번 랜덤이다(`explore(flip=…)`).
  - 한 바퀴(설정한 칸 수)를 보면 쉬었다가 더 바깥쪽 새 지역을 본다.
  - 본 칸은 `~/scout/visited.json`에 폰 GPS 위치(`dumpsys location`)와 함께 저장한다.
  - 중지했다가 **같은 자리(약 100m 안), 같은 줌 설정**에서 다시 시작하면, 설정한 '본 곳 기억' 시간(기본 2시간) 안에 본 칸은 건너뛰고 이어서 본다.
  - 위치가 바뀌었거나 위치를 모르면 처음부터 본다. [리셋]하면 기억도 지운다.
  - 폰 화면 모드에서는 시작할 때 '내 위치' 버튼(`ui/locate`)을 눌러 지도를 가운데로 맞춘다.
- **화면 가장자리 버섯**: 이름표가 화면 밖에 뜨므로 지도를 끌어 가운데로 옮겨서 누르고, 끝나면 원래 자리로 되돌린다. 버섯이 여러 개면 가운데 것부터 누른다.

**발열·배터리·안정성**
- **발열**
  - 가상 화면은 초당 20번만 그린다(안드로이드 14+).
  - 지금 찾는 버섯 사진만 비교한다.
  - 블룸이 살아 있는지는 5칸에 한 번만 확인한다.
  - 캡처는 JPEG를 쓴다.
  - 설정에서 가상 화면 크기를 줄일 수 있다.
- **배터리·용량**
  - 충전 안 할 때 배터리가 15% 이하면 멈춘다.
  - 자동 멈추기 설정이 있다.
  - 기록 사진은 30장만 남긴다.
  - 앱은 로그 끝 64KB만 읽는다.
  - 확인용 사진은 다 쓴 뒤 한 번에 바꿔치기한다. 그래야 엑스박스가 안 뜬다.
- **안정성**
  - 화면이 까맣게 나오면(블룸이 멈춤) 멈추지 않고 블룸을 다시 띄운다. 지도가 3번 연속 안 움직이면 블룸에 포커스를 주고 광역 지도로 다시 들어가 보고, 6번이면 블룸을 껐다 다시 띄우고, 9번이면 멈춘다.
  - 키보드: 가상 화면에 `STEAL_TOP_FOCUS_DISABLED` 플래그(1<<16, 안드로이드 14+)를 줘서, 탐지기가 가상 화면을 눌러도 다른 앱의 키보드 입력(지우기 등)을 뺏지 않는다(폰에서 미확인).
  - **포커스**: 다른 앱을 쓰는 동안 가상 화면의 블룸은 지도 위 버섯 터치를 무시한다(사용자 진단: 앞 앱 = 브라우저, 누르기 전후 화면이 물결 말고는 같음). 그래서 버섯을 누르는 동안만(`bloom_focus()`) 도우미의 `focus <화면>`(IActivityTaskManager.setFocusedTask)로 블룸에 포커스를 주고, 끝나면 `focus-task <원래 작업>`으로 돌려준다. 폰에서 미확인.
  - 앱 서버만 꺼지고 찾기 작업이 살아 있으면, 위젯으로 다시 켤 때 그 작업을 끄지 않고 이어받는다(`Adopted`, `scan_state.json`). 예전에는 '주인 없는 작업'으로 보고 꺼서 위젯을 누르면 찾기가 멈췄다. 설치 묶음이 안드로이드 12+ 자식 프로세스 제한(phantom process)도 끈다.
  - [리셋]은 다른 서버가 띄운 찾기 작업까지 멈춘 뒤 지운다.
  - 앱이 켜져 있을 때 위젯을 누르면 응답이 늦어도(찾는 중이라 바쁨) 절대 끄지 않고 화면만 연다.
  - 찾기가 오류로 멈추면 30초 뒤 자동으로 다시 시작한다(최대 3번).
  - 업데이트할 때 남아 있던 찾기 작업을 정리한다.
  - 브라우저를 내렸다 열면 바로 새로 불러온다. '꺼짐'은 화면이 보일 때 3번 연속 실패해야 띄운다.
- **바다**: 기준은 60%(`SEA_LIMIT`)다. 바다가 섞인 칸 안의 버섯도 찾고, 60%가 넘는 칸에서만 그 너머로 안 나간다.

## 7. 남은 일 / 아이디어

- **이름표 놓침(다른 앱 사용 중)**: 진단으로 포커스 문제임을 확인했고 v53에서 `bloom_focus()`로 고쳤다. 폰에서 '블룸을 잠깐 앞으로' 뒤에도 놓치면, 진행 기록의 '실패:' 문구(권한 등)를 보고 다른 방법(가상 화면 플래그에서 `STEAL_TOP_FOCUS_DISABLED` 빼기)을 검토한다.
- **단독 앱(APK)**: 보면서 찾기는 화면 녹화 권한 + 접근성 서비스로 Shizuku 없이도 가능하다. 백그라운드(가상 화면)와 핀치 줌아웃은 셸 권한(Shizuku)이 꼭 필요하다.
- 다른 기기에서는 앱 위치나 크기 비율이 다를 수 있다. 템플릿은 화면 너비 1019px 기준으로 맞춰 비교한다.
